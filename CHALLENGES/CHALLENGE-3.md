## Task
Build a Python-based security scanner that helps identify common security weaknesses in a system or website you own or have explicit permission to test.

Requirements:
1. Check website security headers.
2. Identify common HTTPS and TLS configuration issues.
3. Scan local files for accidentally exposed secrets using test patterns.
4. Generate a report explaining detected issues and possible fixes.
5. Include error handling, documentation, and example results.

Bonus: Add a simple web interface, severity ratings, or JSON report export.

Safety: Only test systems you own or are explicitly authorized to assess. Do not attempt unauthorized access, exploitation, or data extraction.

Language: Python
Libraries: requests, socket, ssl, re, pathlib, bandit, pytest
